# Ветка `moodle-plugin` — «КосмоЛаб» как элемент курса Moodle

Эта ветка содержит всё то же, что и `main` (рабочая платформа «КосмоЛаб»),
плюс готовый плагин для Moodle в каталоге [`moodle/`](moodle/).

**Ветка `main` и GitHub Pages этой веткой не затрагиваются**: онлайн-версия платформы
(`https://pavelb-coder.github.io/sim-kosmo/`) продолжает работать как раньше —
Pages публикует только `main`.

---

## Что внутри

```
moodle/
├── mod/cosmolab/            исходники плагина (mod_cosmolab)
│   ├── README.md            подробная инструкция: установка, настройка, отчёты, ошибки
│   └── tests/               PHPUnit-тесты вспомогательных функций
├── tools/build-zip.sh       сборка установочного архива
├── tools/check-plugin.sh    самопроверка плагина без установленного Moodle
├── tools/logic-test.php     автономный тест логики (35 проверок, без Moodle)
└── dist/mod_cosmolab.zip    готовый архив для «Установки плагинов» в Moodle
```

`mod_cosmolab` — элемент курса, который встраивает виртуальную лабораторию в Moodle
через `<iframe>` и принимает результаты из платформы по `postMessage` → AJAX:

- 5 лабораторий и 17 практикумов на выбор в настройках элемента;
- автоматическая оценка в журнале (максимальный балл настраивается);
- правило завершения «Студент должен выполнить задание»;
- отчёт преподавателя с выгрузкой в CSV;
- резервное копирование и восстановление вместе с результатами;
- Privacy API (экспорт/удаление данных ученика);
- русская и английская локализация;
- совместимость: Moodle 3.9 … 4.5, PHP 7.4+.

## Быстрая установка

1. Возьмите `moodle/dist/mod_cosmolab.zip` (или соберите: `cd moodle && ./tools/build-zip.sh`).
2. Moodle → **Администрирование сайта → Плагины → Установка плагинов** → загрузите ZIP.
3. **Администрирование сайта → Уведомления** → завершите установку.
4. В курсе: **Добавить элемент или ресурс → КосмоЛаб** → выберите лабораторию и практикум.

Подробности (включая размещение своей копии платформы в школьной сети и типовые ошибки) —
в [`moodle/mod/cosmolab/README.md`](moodle/mod/cosmolab/README.md).

## Самопроверка без Moodle

```bash
cd moodle
./tools/check-plugin.sh
```

Скрипт проверяет синтаксис PHP, XMLDB и SVG, паритет языковых строк `en`/`ru`,
собранный AMD-модуль, логику плагина (35 автотестов на заглушках ядра),
обязательные файлы и содержимое ZIP.

## Как обновлять плагин

```bash
git fetch origin
git checkout moodle-plugin
git rebase origin/main      # подтянуть свежую платформу из main
cd moodle && ./tools/check-plugin.sh && ./tools/build-zip.sh
```

После правок `amd/src/bridge.js` не забудьте пересобрать `amd/build/bridge.min.js`
(`npx grunt amd --root=mod/cosmolab` в каталоге Moodle) — в репозитории лежит уже
собранная версия, поэтому Node.js при установке не требуется.

## Связь платформы и Moodle

| Направление | Сообщение |
|---|---|
| платформа → Moodle | `ready`, `lab-changed`, `mission-start`, `progress`, `mission-complete`, `state` |
| Moodle → платформа | `config`, `ping`, `request-state` |

Параметры запуска внутри фрейма: `?task=<id практикума>&embed=1`
или `?lab=<ключ лаборатории>&embed=1` для свободного режима.
