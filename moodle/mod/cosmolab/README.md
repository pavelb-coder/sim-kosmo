# КосмоЛаб для Moodle — `mod_cosmolab`

Элемент курса Moodle, который встраивает виртуальные лаборатории платформы **«КосмоЛаб»**
(sim-kosmo) прямо в курс: ученик открывает практикум, а Moodle сохраняет прогресс,
зачёт и оценку. Регистрация на стороннем сервисе и установка ПО не нужны.

- Совместимость: **Moodle 3.9 … 4.5** (`$plugin->supported = [39, 405]`), PHP 7.4+.
- Компонент: `mod_cosmolab`, каталог установки: `moodle/mod/cosmolab`.
- Лицензия: GPL v3 или новее.

---

## 1. Что умеет плагин

| Возможность | Описание |
|---|---|
| 5 лабораторий | CubeSat/«ОрбиКрафт», орбитальная механика, ракета и CanSat (OpenRocket), приём УКВ и ДЗЗ, СЖО станции |
| 17 практикумов | Задание с автопроверкой выбирается в настройках элемента и открывается в лаборатории |
| Свободный режим | «Песочница» без автопроверки — для проектной работы и демонстраций |
| Оценка | Зачтённое задание автоматически попадает в журнал оценок (максимальный балл настраивается) |
| Завершение | Своё правило завершения «Студент должен выполнить задание» + стандартное отслеживание просмотра |
| Отчёт | Страница результатов для преподавателя с выгрузкой в CSV |
| Резервное копирование | Полный backup/restore элемента вместе с результатами учеников |
| Приватность | Провайдер Privacy API: экспорт и удаление персональных данных |

## 2. Установка

### Вариант А. Через ZIP (проще всего)

1. Скачайте готовый архив `mod_cosmolab.zip` (каталог `moodle/dist` этого репозитория) или соберите его:
   ```bash
   git clone -b moodle-plugin https://github.com/pavelb-coder/sim-kosmo.git
   cd sim-kosmo/moodle && ./tools/build-zip.sh
   ```
2. В Moodle: **Администрирование сайта → Плагины → Установка плагинов** → перетащите ZIP →
   «Установить из ZIP-архива» → «Обновить базу данных Moodle».
3. Проверьте: **Администрирование сайта → Уведомления** — плагин `mod_cosmolab` должен быть
   установлен без ошибок.

### Вариант Б. Копированием файлов

```bash
git clone -b moodle-plugin https://github.com/pavelb-coder/sim-kosmo.git
cp -r sim-kosmo/moodle/mod/cosmolab /path/to/moodle/mod/cosmolab
php /path/to/moodle/admin/cli/upgrade.php --non-interactive
```

> Каталог должен называться именно `cosmolab`: имя папки = имя компонента без префикса `mod_`.

## 3. Добавление задания в курс

1. В курсе включите «Режим редактирования» → **Добавить элемент или ресурс** → **КосмоЛаб**.
2. Заполните:
   - **Название** — например, «Практикум 9. Сверхзвук».
   - **Адрес платформы «КосмоЛаб»** — по умолчанию публичная сборка
     `https://pavelb-coder.github.io/sim-kosmo/`. Укажите адрес своей копии, если платформа
     размещена в школьной сети (см. раздел 5).
   - **Лаборатория** и **Практикум** — какой стенд и какое задание открывать.
   - **Высота фрейма** — 820 px для ноутбука 1366×768, 1000–1200 px для проектора.
   - **Выставлять оценку** и **Максимальный балл** — попадание результата в журнал.
   - **Завершение → Студент должен выполнить задание** — элемент закрывается по зачёту.
3. Сохраните. Ученик открывает элемент и сразу работает в лаборатории.

## 4. Как это работает

```
┌──────────────────────── Moodle (mod_cosmolab/view.php) ────────────────────────┐
│  статус: лаборатория · практикум · оценка · «Зачтено / В процессе»            │
│  ┌──────────────────── iframe (КосмоЛаб, GitHub Pages) ────────────────────┐  │
│  │  лаборатория + практикум + автопроверка                                 │  │
│  └────────────────────────────────────────────────────────────────────────┘  │
│  amd/src/bridge.js:  postMessage ⇄ core/ajax → mod_cosmolab_submit_result    │
└──────────────────────────────────────────────────────────────────────────────┘
```

1. `view.php` формирует адрес платформы с параметрами `?task=<практикум>&embed=1`.
2. Платформа (мост `js/integration/moodle.js`) отправляет в родительское окно сообщения:
   `ready`, `mission-start`, `progress`, `mission-complete`.
3. Модуль `bridge.js` проверяет `event.origin` (он должен совпадать с адресом платформы),
   отправляет AJAX-запрос `mod_cosmolab_submit_result` и обновляет индикаторы на странице.
4. Сервер записывает результат в таблицу `cosmolab_progress`, пересчитывает оценку
   (`cosmolab_update_grades`) и завершение (`completion_info`).

Успех «залипает»: если задание уже зачтено, повторные попытки не отнимают зачёт,
а сохраняется лучший балл. Счётчик попыток хранится отдельно.

### Внешние функции (AJAX)

| Функция | Назначение |
|---|---|
| `mod_cosmolab_submit_result` | сохранить прогресс/зачёт, обновить оценку и завершение |
| `mod_cosmolab_get_result` | вернуть текущий статус ученика в элементе |

Обе функции требуют возможностей `mod/cosmolab:submit` и `mod/cosmolab:view`
и доступны только внутри Moodle (тип `ajax`), без публикации в мобильном сервисе.

## 5. Своя копия платформы (школьная сеть без доступа в интернет)

1. Скопируйте содержимое этого репозитория (ветка `main`) на школьный сервер, например
   в каталог, который отдаёт веб-сервер: `https://school.local/sim-kosmo/`.
2. В настройках элемента укажите **Адрес платформы** — `https://school.local/sim-kosmo/`.
3. Адрес должен быть доступен **из браузера ученика** (не изнутри Docker Moodle).

Платформа статическая — достаточно любого веб-сервера или `node server.js --port 8086`
из корня репозитория.

## 8. Типовые проблемы

| Симптом | Что проверить |
|---|---|
| Внутри элемента пусто, серая рамка | Школьный прокси/файрвол блокирует внешние фреймы. Откройте ссылку «Открыть лабораторию в новой вкладке» или разместите платформу локально (раздел 5) |
| Результат не появляется в журнале | Включена ли опция «Выставлять оценку», выставлен ли максимальный балл > 0, есть ли у ученика возможность `mod/cosmolab:submit` |
| Задание не «зачитывается» | В элементе должен быть выбран практикум, а не «Свободный режим»; проверьте, что ученик действительно выполнил цель задания |
| Оценка не обновилась после правки балла | Откройте элемент заново или запустите пересчёт оценок курса (журнал → пересчитать) |
| Нужно очистить результаты | В курсе: **Сброс** → блок «КосмоЛаб» → «Удалить все результаты учеников» |

## 9. Разработка

```bash
# PHPUnit (нужна установленная тестовая среда Moodle)
vendor/bin/phpunit --testsuite mod_cosmolab_testsuite

# Проверка стиля кода (Moodle CodeSniffer)
vendor/bin/phpcs --standard=moodle mod/cosmolab

# Пересборка AMD-модуля после правки amd/src/bridge.js
cd /path/to/moodle && npx grunt amd --root=mod/cosmolab
```

В репозитории уже лежит собранный `amd/build/bridge.min.js`, поэтому плагин работает
сразу после установки, без Node.js и grunt.
