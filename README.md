# КосмоЛаб (`sim-kosmo`) — Виртуальные лаборатории Космоквантума

Браузерная платформа интерактивных лабораторных стендов и практикумов для детских технопарков **«Кванториум» (направление Космоквантум)**, профилей НТО и проектных треков CanSat / Space-π. Работает прямо в браузере без установки ПО, внешних библиотек и регистрации.

## ⚡ 2. Быстрый запуск одной командой из GitHub (порт `8086`)

Скрипты сами скачивают (или обновляют) репозиторий в домашнюю папку и поднимают локальный сервер на порту **`8086`** (с доступом для всех компьютеров учебной аудитории по локальной сети `0.0.0.0:8086`).

### Ubuntu / Linux (терминал)
```bash
curl -fsSL https://raw.githubusercontent.com/pavelb-coder/sim-kosmo/main/run-online.sh | bash
```

### Windows 10 / 11 (PowerShell)
```powershell
irm https://raw.githubusercontent.com/pavelb-coder/sim-kosmo/main/run-online.ps1 | iex
```

После запуска платформа доступна по адресу: **`http://localhost:8086`** (и `http://<IP-компьютера>:8086` в локальной сети класса).

## 💻 3. Обычный локальный запуск (Windows и Ubuntu, порт `8086`)

Проект **не требует `npm install` или сборки** — работает как на чистом **Node.js**, так и через встроенный **Python 3** (резервный режим, если Node.js не установлен на школьном ПК).

### На Windows
1. Клонируйте или скачайте архив репозитория:
   ```cmd
   git clone https://github.com/pavelb-coder/sim-kosmo.git
   cd sim-kosmo
   ```
2. Запустите двойным кликом файл **`start-windows.bat`** (или из консоли `start-windows.bat`).
   - Скрипт автоматически запустит сервер на порту **`8086`** и откроет браузер на `http://localhost:8086`.
   - При необходимости можно передать другой порт аргументом: `start-windows.bat 8086`.

### На Ubuntu / Linux
1. Клонируйте репозиторий и запустите скрипт:
   ```bash
   git clone https://github.com/pavelb-coder/sim-kosmo.git
   cd sim-kosmo
   chmod +x start-ubuntu.sh install-ubuntu-service.sh
   ./start-ubuntu.sh
   ```
   Сервер запустится на **`0.0.0.0:8086`** (`http://localhost:8086`). Если открыт файрвол `ufw` и нужен доступ с соседних ПК учеников:
   ```bash
   sudo ufw allow 8086/tcp
   ```
2. **Автозапуск в качестве фонового сервиса `systemd` в Ubuntu (по желанию):**
   ```bash
   sudo ./install-ubuntu-service.sh
   ```
   Управление сервисом:
   ```bash
   sudo systemctl status sim-kosmo
   sudo systemctl restart sim-kosmo
   ```

## 🚀 Лаборатория 3: функционал OpenRocket

Третий стенд повторяет рабочий процесс настоящего **OpenRocket** — от проекта компоновки до отчёта о полёте, но целиком в браузере и на русском языке.

### Дерево компонентов и инспектор
- Иерархия «Ракета → ступени → компоненты»: обтекатель, носовой балласт, корпусная труба, отсек CanSat, система спасения, стабилизаторы, boat-tail, двигатель, корпус и стабилизаторы бустера.
- Щелчок по узлу дерева **или по элементу на 2D-чертеже** открывает инспектор с параметрами именно этого компонента.
- 6 материалов корпуса и стабилизаторов (углепластик, стеклопластик, ABS/PLA, крафт-картон, авиафанера, бальза) с реальной плотностью и толщиной стенки.
- 6 форм головного обтекателя: ряд Хаака (фон Карман), оживальный, параболический, эллиптический, конический, притупленный.
- Профили стабилизаторов (аэродинамический/ромб, скруглённые кромки, прямоугольное сечение), стреловидность, корневая и концевая хорда, размах, количество (3/4/6).
- Качество поверхности — от полированной (2 мкм) до необработанной (150 мкм), влияет на сопротивление трения.
- **Одна или две ступени**: отделяемый бустер со своим двигателем и задержкой запуска маршевой ступени.
- **Системы спасения:** барометр в апогее, **Dual-Deploy** (вытяжной + основной купол на заданной высоте), таймер вышибного заряда.

### Двигатели и файлы
- 8 встроенных МРД от C6 до K550W с реальными кривыми тяги (класс, суммарный импульс, время работы, массы).
- **Импорт двигателя из файла RASP `.eng`** (стандарт OpenRocket / ThrustCurve.org) — как с диска ученика, так и встроенный пример CosmoLab D12 одной кнопкой.
- **Экспорт проекта в `rocket.ork.json`** (конфигурация, атмосфера, результаты анализа и последнего полёта), **CSV массовой сводки** и **CSV телеметрии полёта** (t, высота, скорость, Мах, перегрузка, тяга, сопротивление, Cd).

### Четыре расчётных вида + полёт
1. **Чертёж 2D** — масштабный боковой вид с размерными линиями (длина, калибр, обтекатель), маркерами **ЦМ (CG)** и **ЦД (CP)**, скобкой запаса устойчивости и кликабельными компонентами; под чертежом — массовая сводка по компонентам.
2. **Вид сзади** — количество и размах стабилизаторов, габарит двигателя в корпусе и **кривая тяги F(t)** выбранного двигателя (для двухступенчатой схемы — обе ступени).
3. **Аэротруба** — линии тока, ползунки числа Маха (0.05…2.6) и угла атаки, разложение Cd на трение / давление+волновое / донное и график **Cd(Mach)** с отмеченной трансзвуковой зоной.
4. **Плоттер** — многоканальный график высоты, скорости, числа Маха и перегрузки за полёт и **таблица сравнения симуляций** всех пресетов.
5. **Полёт** — 2D-траектория с ветром, маркерами дискретных событий (сход с направляющей, выгорание, разделение ступеней, апогей, выброс куполов, посадка), воспроизведением ×0.25…×4 и живым осциллографом.

### Расчётное ядро (как в OpenRocket)
- **Расширенный метод Барроумена** для ЦД, включая дестабилизирующее влияние boat-tail и стабилизаторы бустера.
- Покомпонентный расчёт массы и ЦМ (оболочки по площади поверхности, парашюты, CanSat, топливо с учётом выгорания).
- Сопротивление: трение по смоченной площади и шероховатости, давление формы, донное сопротивление, волновой рост в транс- и сверхзвуке.
- 2D-симуляция с моделью атмосферы, ветровым сдвигом, «вилянием» (weathercocking), проверкой скорости схода с направляющей, разрушением строп при больших скоростях раскрытия и кувырком при запасе устойчивости < 0.3 кал.
- Панель **предупреждений в стиле OpenRocket**: неустойчивость, избыточный запас, T/W < 1.25, двигатель не влезает в корпус, чрезмерное удлинение, поздний ввод купола.

### Практикумы по ракетостроению
7. Кувырок из-за ЦД впереди ЦМ — добиться запаса 1.2–2.8 кал. и мягкой посадки.
8. Спасение CanSat: барометрический выброс и касание < 6.5 м/с с высоты > 850 м.
9. Сверхзвуковой зонд: апогей ≥ 3 000 м и Мах ≥ 1.2 (K550W, углепластик, boat-tail).
10. Тандем: включить вторую ступень, разделение в полёте и апогей ≥ 1 500 м.
11. Импорт двигателя из `.eng`, проверка класса по импульсу и сертификационный пуск.
