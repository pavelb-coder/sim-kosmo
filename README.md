# КосмоЛаб (`sim-kosmo`) — Виртуальные лаборатории Космоквантума

Браузерная платформа интерактивных лабораторных стендов и практикумов для детских технопарков **«Кванториум» (направление Космоквантум)**, профилей НТО и проектных треков CanSat / Space-π. Работает прямо в браузере без установки ПО, внешних библиотек и регистрации.

## Лабораторные стенды

1. **CubeSat · ОрбиКрафт (`?lab=cubesat`)** — сборка бортовых подсистем наноспутника 1U, контроль массы и энергобаланса СЭП, испытательный подвес с имитатором Солнца и магнитной рамкой, программируемый БКУ (B-dot, ПД-регулятор маховика), стенд имитации отказов на шине RS-485 и 4-канальный осциллограф.
2. **Орбитальная механика и манёвры (`?lab=orbit`)** — численное интегрирование орбит (РК4), расчёт расхода топлива по формуле К. Э. Циолковского, гомановские переходы до МКС и ГСО, торможение в атмосфере, радиационные пояса Ван Аллена и трасса полёта с зонами радиовидимости наземных станций (Красноярск, Королёв, Восточный).
3. **Конструктор ракет и CanSat (`?lab=rocket`)** — виртуальная аэродинамическая труба с расчётом Центра масс (ЦМ), Центра давления (ЦД) и запаса устойчивости в калибрах, настройка двигателя и системы спасения по барометру BMP280, полигон пуска 0–5 000 м.
4. **Приёмная станция УКВ «Вьюнок» Web-SDR + ДЗЗ (`?lab=sdr`)** — сопровождение пролёта спутника по азимуту и углу места, компенсация эффекта Доплера на водопаде спектра, построчный декодер снимков APT/LRPT и мультиспектральный анализ ДЗЗ (RGB, NIR, тепловой TIR, индекс NDVI) для поиска лесных пожаров и паводков.
5. **Замкнутая СЖО орбитальной станции (`?lab=lss`)** — баланс `O₂`, `CO₂`, `H₂`, воды и теплоотвода СТР для экипажа из 1–6 космонавтов (электролиз воды «Электрон-ВМ», адсорбер «Воздух», патроны `LiOH`, реактор Сабатье).

## Возможности для наставника

- **15 готовых практикумов и нештатных ситуаций** с автоматической проверкой выполнения.
- **Прямые ссылки на стенд и задание:** `?lab=cubesat&task=broken_polarity` или полная ссылка с закодированным состоянием стенда.
- **Сохранение и сдача работ файлом `.cosmolab`** (поддерживается перетаскивание файла в окно браузера).
- **Режим встраивания `<iframe>`:** добавьте `&embed=1` к URL для встраивания в LMS / Stepik / Moodle.

## Локальный запуск

Проект не требует `npm install` или сборки:

```bash
node server.js
```

После запуска откройте `http://localhost:3000` (также проект полностью совместим с прямым хостингом статики на **GitHub Pages**).
